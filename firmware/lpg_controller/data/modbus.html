Holding Registers — Live Values

RegisterNameValueUnit
0x1001Live Weight—kg × 100
0x1002Tare Weight—kg × 100
0x1003Net Weight—kg × 100
0x1004Filling Status—0=idle 1=filling 2=complete
0x1005Target Weight—kg × 100

Connection Example (Python)

from pymodbus.client import ModbusTcpClient
c = ModbusTcpClient('192.168.x.x', port=502)
c.connect()
r = c.read_holding_registers(0x1001, count=6, slave=1)
live_kg = r.registers[0] / 100.0
