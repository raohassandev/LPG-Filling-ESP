Recommended RTU Settings (Commercial / HMI)

Factory default for new / erased devices: 115200 8N1, Slave 1.

Existing devices preserve their saved NVS baud rate after a firmware update. If this device still shows 9600, the NVS contains a previously saved 9600 setting.
Supported compatibility baud rates: 9600, 19200, 38400, 57600, 115200.
Lower baud rates are supported for compatibility but result in longer physical wire time for large register reads.
At 115200 a 19-register read takes ~3 ms of wire time. At 9600 the same frame takes ~35 ms.
Internal firmware processing reads from RAM cache — firmware processing latency is deterministic regardless of baud.
Application Load Percent is a main-loop utilisation estimate, not guaranteed FreeRTOS CPU load.
Firmware update does not overwrite saved RTU settings. To apply 115200, use the Apply Recommended button below (requires login).

Protocol Settings

Reading active settings above does not require a PIN. Changing settings requires the Manufacturing PIN.

Data bits fixed at 8. TCP port fixed at 502. Baud/parity changes take effect immediately on RTU (UART reinitialized after response). Slave address change takes effect immediately.
