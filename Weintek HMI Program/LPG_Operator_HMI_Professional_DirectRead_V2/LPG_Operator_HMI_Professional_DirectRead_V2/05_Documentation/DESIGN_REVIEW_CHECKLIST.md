DESIGN REVIEW CHECKLIST
=======================

This package was rebuilt programmatically, not as AI-generated unmeasured artwork.

Checkpoints:
- Canvas is 800x480 px.
- Background contains fixed labels and placeholders only.
- Separate assets have exact pixel sizes and catalog.
- Alarm pill is 170x36 px, larger than the earlier test version and designed for short header alarms.
- Operator terminology is simplified.
- No manual tare input on operator screen.
- No duplicate Target KG / Target Weight naming on screen.
- Direct controller read tags are the main display method.
- Macros do not copy live controller data to duplicate LW values.
- Progress is the only calculated local display value.
