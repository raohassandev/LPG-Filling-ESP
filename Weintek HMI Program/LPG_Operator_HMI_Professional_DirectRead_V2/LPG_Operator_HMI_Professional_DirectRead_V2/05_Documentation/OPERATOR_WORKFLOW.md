OPERATOR WORKFLOW
=================

Screen terminology is designed for non-technical filling staff.

OLD TERMS REMOVED
-----------------
Write Presets  -> Ready / Apply Setup
Prepare        -> Ready / Apply Setup
Target Weight  -> Target / Desired KG
Manual Tare    -> Capture Tare
Mode KG        -> By KG
Mode Amount    -> By Amount

NORMAL FLOW
-----------
1. Select By KG or By Amount.
2. Enter Price per KG.
3. Enter Desired KG or Desired Amount.
4. Place cylinder.
5. Press Capture Tare.
6. Press Ready / Apply Setup.
7. Press Start Filling when ready.
8. Press Complete / Next Cylinder when complete.

SAFETY FLOW
-----------
- Stop Filling is available during active filling.
- Reset / Clear is used after stopped/fault/clear condition.
- Alarm screen should show the detailed reason.
